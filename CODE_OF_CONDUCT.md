# Code of Conduct

## Our Standard

This project is committed to a harassment-free experience for everyone.

Examples of positive behavior include:

- Being respectful in discussion and review
- Giving actionable technical feedback
- Assuming good intent while staying precise
- Focusing on what improves the project

Examples of unacceptable behavior include:

- Harassment or personal attacks
- Trolling, insults, or bad-faith arguments
- Publishing private information without permission
- Repeatedly derailing technical discussion

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, issues, and pull requests that violate this code of conduct.

## Scope

This code of conduct applies in project spaces, including issues, pull requests, and discussions.
